# Abyss Atlas · 深淵圖鑑

An interactive three.js atlas of six deep-sea creatures (dumbo octopus, anglerfish, vampire squid, barreleye, gulper eel, nautilus). Every model is procedural — no GLB files. Drag to rotate, scroll or pinch to zoom, open a close-up detail, switch light/dark and EN/中文.

Static site with no build step: serve the folder and open `index.html`. `?s=<id>` opens a given species.
